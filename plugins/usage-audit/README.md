# usage-audit

過去のセッションの記録から、利用枠を重くしている箇所を見つけ、節約の見込みが大きい順に改善策を提案します。

## 使い方

Claude に「どこで利用枠を使いすぎているか見て」「節約のしかたを教えて」のように頼みます。直近 7 日の記録を集計し、効きの大きい直し方から順に伝えます。範囲は「全部のプロジェクトで」「先月の分で」のように指定できます。エージェント定義の書き換えなど、ファイルで直せるものは、頼めば了承を取ってから直します。

集計はこの PC の中だけで行い、記録はどこにも送りません。会話の本文は出力しません。
実行には Node.js 18 以降が要ります。

インストール方法は、[リポジトリの README](../../README.md) を見てください。

Claude Code v2.1.295 のデスクトップアプリ（Code タブ）で動作を確認しています。
