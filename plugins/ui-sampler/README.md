# ui-sampler

mod が UI を描ける場所を、一通り試すための見本です。
表示する中身はすべてダミーです。
どの場所が実際に出るかは、Claude Code のバージョンや、ターミナルかデスクトップアプリかで変わります。

## 使い方

`/ui-sampler` で「UI 見本市」のパネルが開きます。
パネルのボタンで、トースト、ステータス行、ログ行、system 通知、質問ダイアログを出せます。

読み込んでいる間は、標準の表示も次のように変わります。

- スピナーの文言が「見本市を準備中」になる
- フッターのモード表示に `sampler` が出る
- `/ui-sampler` の結果の行に ✔ が付く
- ヒント行の末尾に文言が付く

パネルの「診断」の欄には、ヒント行とモード表示のフックが呼ばれた回数と、受け取った props が出ます。
フックが呼ばれていないのか、呼ばれても描画されていないのかを見分けるためのものです。
