# ボードを使う

ボードは、会話のログに流れてしまう情報を、画面の右のパネルに残しておく作業メモです。Claude が書き込み、人は基本的に見るだけです。入力欄の上の帯に「ボード N件」と出ていれば、カードがあります。パネルの先頭の「並行処理」は、動いているサブエージェントが自動で出る区画で、ツールからは読み書きできません。

## ツール

| ツール | 入力 | すること |
| --- | --- | --- |
| `mcp__whiteboard__set_card` | `id`, `title`, `body`, `pin`（省略できる） | カードを追加する。同じ `id` があれば上書きする（表示の位置は変わらない）。`pin: true` で固定、`pin: false` で固定を外す、省略すると今のまま |
| `mcp__whiteboard__remove_card` | `id` | カードを 1 枚消す。無い `id` なら、その旨が返る |
| `mcp__whiteboard__clear` | なし | カードを全部消す |
| `mcp__whiteboard__list_cards` | 省略できる `titles_only`・`id`・`query` | ボードを読む。引数なしは全カードの `id`・`title`・`body` を全文で返す。`titles_only: true` は目次（`id`・`title`・`chars`）、`id` はそのカード 1 枚、`query` は語をすべて含むカードと一致した行を返す。パネルと同じ順（固定が先）で、固定のカードには `pinned: true` が付く |

上限は、カード 20 枚、`title` 60 文字、`body` 4000 文字、`id` は英数字と `_` `-` の 40 文字までです。超えるとツールがエラーを返すので、短くするか、済んだカードを消してからやり直します。

## 利用者の頼み方ごとの動き

- 「ボードにこれを書いて」「残しておいて」: 内容に合う `id` で `set_card` する。すでに同じ話題のカードがあれば、同じ `id` で上書きして更新する。迷うときは先に `list_cards` で何があるかを見る
- 「ボードのあれを消して」: どのカードか分かるなら `remove_card`。曖昧なら `list_cards` で見て、利用者に確かめてから消す。全部と言われたときだけ `clear`
- 「ボードを整理して」: `list_cards` で全部読み、済んだもの・古いものを `remove_card` で消し、重なる話題は 1 枚にまとめて `set_card` で書き直す。何を消して何をまとめたかを、最後に一言で伝える
- 「ボードに何が書いてある？」: `list_cards` の `titles_only: true` で目次を見て、要点だけ答える。内容をそのまま貼り直さない
- 「ボードの手順 3 は？」のように内容を尋ねられたとき、「手順 3 を済みにして」のように指示されたとき: 先に `list_cards` の `query`（語を空白で分けて並べる）か `titles_only: true` で探し、必要なカードだけ `id` を指定して読む。引数なしの `list_cards` は全文を返すので重い。書き換えは、読んだカードの `id` で `set_card` する

## カードの書き方

- `id` は短い英語の名前にする（`plan`、`urls`、`jobs`、`todo` など）。話題が変わらない限り同じ `id` を使い続けるので、後から見て分かる名前にする
- 1 カード 1 話題にする。手順、動いている処理、リンクは別のカードにする
- `title` は見出しとして一目で分かる短さにする
- `body` は Markdown で、要点だけを書く。手順は番号付きの箇条書き、状況は「何が・どうなっている」、リンクは `[名前](URL)` にする。図は、` ```mermaid ` の基本的な flowchart / graph（と、参加者と矢印だけの sequenceDiagram）なら、パネルで図になる。subgraph などそれ以外の mermaid や ASCII の図は、コードブロックとして読める形で表示される（描画はされない）。関係や流れは、箇条書きや表でも伝わる
- 状況が変わったら、同じ `id` で `set_card` し直す。更新のたびに新しいカードを増やさない
- `pin: true` は、人が常に見ていたいカード（今の手順の全体像、URL の一覧など）だけに使う。固定したカードはパネルの上に並ぶので、使いすぎると意味がなくなる。固定を外すときは `pin: false`。`pin` を省略して上書きすると、固定は今のまま
- 用が済んだカードは消す。残すのは、これから先も見返すものだけにする

## ほかのセッションのボード

パネルの下には、ほかのセッションが残したボードの一覧が出ます。そのカードを今のボードに写す [取り込む] と、ボードを消す [消す] は、人がパネルのボタンで操作します。Claude が呼ぶツールはありません。人に「前のボードを引き継ぎたい」と言われたら、パネルの一番下の一覧から [取り込む] を押すよう案内し、取り込んだあとは `list_cards` で内容を読み返します。

## 使いどころ

利用者に頼まれなくても、会話の中で流れ去ってしまう次のような情報は、ボードに残すと役に立ちます。ただし、会話にもう書いたことをただ写すためには使いません。

- 数回のやり取りにまたがる手順やチェックリスト
- 並行して動かしている処理（バックグラウンドのタスクなど）の今の状況。サブエージェントの実行状況は、パネルの上の「並行処理」に自動で出るので、カードに写さない
- このセッションで開く URL や、参照するファイルの場所
- 利用者と決めたこと
