# whiteboard

Claude が書き込む作業ボードです。手順、動かしている処理、URL、決めたことなど、チャットで流れてしまう情報を、カードにして画面の右に残します。「さっき言っていた手順をもう一回」と聞き直す手間と、そのためのトークンを減らします。

## インストール

インストール方法は、[リポジトリの README](../../README.md) を見てください。

## 使い方

Claude に頼みます。

```text
ボードに今日の作業手順を書いて
ボードに今開いているプレビューの URL を残して
ボードの手順 3 は？
ボードの手順 3 を済みにして
ボードのあれを消して
ボードを整理して
```

頼まなくても、Claude が自分でボードに書くことがあります。カードの書き換えにボタンはありません。

カードは、そのセッションに保存され、アプリを閉じて開き直しても残ります。

## パネルの見方

入力欄の上の帯に「ホワイトボード 3件」と [開く] が出ます。押すと右にパネルが開き、カードが追加した順に並びます。`/whiteboard` でも開けます。カードごとに、タイトル、その下に最後に書いた時刻、本文が出ます。

時刻の行には、カードの今の様子が付きます。

- 本文に `- [ ]` / `- [x]` のチェックリストがあると「3/5」のように進み具合が出て、全部済むと「済」が付きます
- 最後に送った依頼のあとで Claude が書いたカードには「新規」か「更新」が付き、更新したカードには「+3 −1 行」と増えた行と消えた行の数が出ます。次の依頼を送ると消えます
- 固定していないカードを 3 時間（設定 `staleHours`）書き換えていないと「古い」と付いて、題が薄くなります。勝手には消えません

長いカードは畳まれて出て、[続きを表示] で開けます。固定したカードと、最後の依頼のあとで Claude が書き換えたカードは開いたまま出ます。

カードが 6 枚以上あると、一覧の上に入力欄が出ます。打った語でカードを絞り込めます（空白で区切ると、すべてを含むもの）。パネルを開き直すと解けます。

カードが 3 枚以上あると、件数の横に [並び: 追加順] が出ます。押すと最後に書き換えた順に並び替わり、もう一度押すと戻ります（固定したカードは上のまま）。

常に見ていたいカード（今の手順の全体像、URL の一覧など）は、Claude に頼んで「固定」にできます。固定したカードは上に並びます。

帯には、件数のほかに「更新 2枚」「古い 2枚」と、いちばん最近書き換えた固定カードの題（「ホワイトボード 3件 · 朝の確認リスト 2/5」）が出ます。パネルを開かなくても今の要点が分かります。幅が足りないときは、題から省きます。

## カードの色

「deploy のカードは青で」のように頼むと、カードの枠（太い線になります）と見出しに色が付きます。色は red、orange、yellow、green、blue、purple、gray の 7 つで、none で外せます。色に決まった意味はありません。意味を決めたいときは、会話で Claude に伝えてください（「止まっている作業は赤にして」など）。

既定の色はテーマに合わせて変わります。見分けにくい色があれば、設定 `colors` で好きな色に割り当て直せます。

色だけでは見分けにくいときは、設定 `styleMarks` をオンにすると、見出しと帯の題の前に色の名前ごとの印（red ●、orange ▲、yellow ◆、green ■、blue ★、purple ✚、gray ○）が付きます（印は色の名前で決まり、`colors` で色を変えても変わりません）。

## カードに書けるもの

本文は Markdown です（見出し、箇条書き、リンク、コード、表）。

` ```mermaid ` の囲みに、基本的な `flowchart` / `graph` と `sequenceDiagram` を書くと、パネルで図になります。`subgraph` は枠で囲んで描きますが、`subgraph` そのものに矢印を引いた図は描きません。描けない書き方は、コードブロックのまま表示されます。ターミナルでは、いつもコードブロックです。

## 前のセッションのボードを引き継ぐ

新しいセッションでカードが 0 件のとき、帯に「引き継げます」と出て、パネルに「前のセッションから引き継ぐ」の枠が出ます。候補は、更新が新しい順に最大 5 件で、日時、フォルダ名（プロジェクトの一番上のフォルダの名前）、枚数、会話の題（なければ最初に打った言葉）、カードのタイトルで見分けられます。

[引き継ぐ] を押すと、そのボードのカードが今のボードに写ります。

- 元のボードは消えず、読み取り専用になり、引き継ぎの候補からも外れます。元のセッションを開けば読めます。元のセッションで [このセッションで書けるように戻す] を押すと、また書けます
- 同じ id のカード（最近消して `undo_card` で戻せるカードも）は飛ばし、カードの枚数の上限（既定 20 枚）までを写します。今のボードにカードがあるときや、飛ばすカードがあるときは、押すと確認の段が出て、入るカード・飛ばすカードを見てから決められます
- 同じフォルダで並行して使っているセッションのボードも候補に出ます。引き継ぎ元がまだ使われていないかを確かめてから押してください
- ほぼ同時に 2 つのセッションが同じボードを引き継ぐと、両方に写しができます
- 見分けるために、各セッションで最初に打った言葉の先頭 60 文字を、ボードと一緒に保存します。保存した会話の題と最初の言葉は、Claude も `list_cards` の `others` で読みます（設定 `handover` をオフにすると保存しません）
- Claude が `others` で読むのは、同じ場所（フルパス）のプロジェクトのボードだけです。場所はそのまま保存せず、パスから作った短い値で見分けます。この仕組みより前の版で書かれたボードは読みません

## Claude が使うツール

Claude は次のツール（`mcp__whiteboard__` で始まります）でボードを操作します。初めて使うときに、許可を求められることがあります。

| ツール | 入力 | 内容 |
| --- | --- | --- |
| `set_card` | `id`, `title`, `body`, `pin` と `style`（省略できる） | カードを追加する。同じ `id` があれば上書きする。`pin` で固定する・外す。`style` で色を付ける・外す |
| `edit_card` | `id`, `find`, `replace`, `all`, `style`（`id` 以外は省略できる） | 本文の一部だけを置き換える。`find` は本文の中で 1 箇所にだけ一致する長さにする（`all: true` なら全部）。`id` と `style` だけなら色だけを変える |
| `append_card` | `id`, `text` | 本文の末尾に足す |
| `remove_card` | `id` | カードを 1 枚消す |
| `clear` | なし | カードを全部消す |
| `list_cards` | なし、または `titles_only` / `id` / `query` / `since` / `others` / `board` | ボードを読む。引数なしは全文。`titles_only` は目次、`id` はそのカード 1 枚、`query` は語で探す、`since` は前に読んだ版から変わったカードだけ。`others` は同じ場所（フルパス）のプロジェクトの前のセッションのボード（新しい順に 5 件まで）を読むだけで、書き換えない（1 枚を読むときは `board` でボードを指す） |
| `undo_card` | `id` | カードの最後の書き換えを 1 つ戻す（もう一度でやり直し）。最近消した 5 枚までは、消したカードも戻せる |

ボードの内容を聞かれたときは、まず `titles_only` か `query` で探し、必要なカードだけ `id` で読みます。会話が圧縮されたときは、圧縮後の要約の末尾にカードの id とタイトルの一覧が付くので、Claude はボードのことを忘れずに続けられます。このプラグインには、使い方を Claude に教えるスキル `whiteboard` も入っています。

## 設定

whiteboard のプラグインの設定で変えます。

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| `handover` | オン | カードが 0 件のとき、前のセッションのボードの一覧と [引き継ぐ] を出す。オフにすると、Claude が前のセッションのボード（保存した会話の題と最初の言葉も）を読む（`list_cards` の `others`）のも断る。オフにしても、引き継いだあとの元のボードの読み取り専用は保たれる |
| `guide` | `off` | 新しいセッションの Claude に、ボードがあることを伝える。`short`: システムプロンプトに毎回同じ短い 1 節（約 120 文字）を足す。`full`: `short` に加えて、入力に `guideKeywords` の語が含まれるときだけ、ツールの使い分けの要点を足す（5 ターンに 1 回まで） |
| `guideKeywords` | `ボード,whiteboard` | `full` のきっかけの語（カンマ区切り） |
| `colors` | 空 | カードの色の割り当て。`red=#D55E00, green=#009E73, blue=suggestion` のように、色の名前ごとにテーマの色名か `#rgb` / `#rrggbb` を書く。書けていない項目は無視され、既定の色のまま |
| `styleMarks` | オフ | 色の付いたカードの見出しと帯の題の前に、色の名前ごとに形の違う小さな印を付ける |
| `bandTitle` | オン | 帯に、いちばん最近書き換えた固定カードの題（チェックリストがあれば進み具合も）を出す |
| `staleHours` | `3` | 固定していないカードを、この時間（時間単位）より長く書き換えていないと「古い」と示す。`0` で示さない |
| `maxCards` | `20` | ボードに置けるカードの枚数の上限（5〜40）。範囲の外は 5 か 40 に、数でなければ 20 になる。多くすると、パネルが長くなり、保存も大きくなる。減らしても、すでにあるカードは消えず、上限より多い間はカードを足せない |

## 上限

| 項目 | 上限 |
| --- | --- |
| カードの枚数 | 20 枚（設定 `maxCards` で 5〜40） |
| タイトル | 60 文字 |
| 本文 | 4000 文字 |
| id | 40 文字（英数字と `_` `-`） |

超えると Claude にエラーが返り、Claude が短くするか、済んだカードを消してからやり直します。
