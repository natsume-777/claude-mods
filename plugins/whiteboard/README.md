# whiteboard

Claude が書き込む作業ボード。手順、並行して動かしている処理、このセッションに関わるリンクなど、チャットで流れてしまう情報をカードにして残します。人は基本的に見るだけで、書き込みと整理は Claude に頼みます。

「さっき言っていた手順をもう一回出して」と頼んで、トークンを使わずに済むようにするためのものです。

## インストール

インストール方法は、[リポジトリの README](../../README.md) を見てください。

## 使い方

Claude に頼みます。

```text
ボードに今日の作業手順を書いて
ボードに今開いているプレビューの URL を残して
ボードの手順 3 は？
ボードの手順 3 を済みにして
ボードのあれを消して
ボードを整理して
```

頼まなくても、Claude が手順などを自分でボードに書くことがあります。書き換えと削除も Claude に頼みます。カードの書き換えにボタンはありません。

## 画面で見えるもの

- **帯**: 入力欄の上に「ボード 3件」と [開く] のボタンが出ます。カードが 1 枚もないときも「ボード 0件」と出るので、そこからパネルを開けます。カードがなく、前のセッションのボードを引き継げるときは「ボード 0件 · 引き継げます」と出ます。このセッションのボードが別のセッションに引き継がれて読み取り専用になっているときは「ボード 8件 · 読み取り専用」と出ます。幅が足りないときは、一言を省いて [ボード 0件] のボタンだけになります
- **パネル**: [開く]（または `/whiteboard`）で、右のパネルが開きます。カードが追加した順に並び、カードごとに、タイトル、カードの id と最後に書いた時刻、本文が出ます。カードがないときは「まだ何も書かれていません」と出ます
- **固定**: Claude は、人が常に見ていたいカード（今の手順の全体像、URL の一覧など）を「固定」にできます。固定したカードは上に並び、タイトルの横に薄く「固定」と出ます。固定の中も、固定でない中も、追加した順です。カードを上書きしても、位置は変わりません

カードは、このセッションに結び付けて保存されます。アプリを閉じて開き直しても、同じセッションを開けば残ります。別のセッションのパネルには出ません。新しいセッションに持ち越したいときは、次の「前のセッションのボードを引き継ぐ」を使います。

## 前のセッションのボードを引き継ぐ

新しいセッションを始めたとき、前のセッションのボードのカードを、このセッションに写せます。

1. ボードが空（「ボード 0件」）のとき、パネルに「前のセッションから引き継ぐ」の枠が出ます。引き継げるボードが 1 件なら中身が開いた形で、複数なら 1 件ずつ閉じた行で並びます（新しい順。このセッションと同じフォルダのボードが先です。5 件まで。それ以上は「ほか N 件」と数だけ出ます）
2. 行には、最後に書いた日時、フォルダの名前、カードの枚数、セッション ID の先頭 8 文字、そのセッションの最初の依頼（会話の題が取れたときは題）、先頭 3 枚のタイトルが出ます。どのボードか分からないときは [中身を見る] で、全カードのタイトルを見られます
3. [引き継ぐ] を押すと、そのボードのカードがこのボードに入ります。固定したカードは固定のまま、カードの時刻もそのままです。結果は、パネルの上に 1 行で出ます（パネルを開き直すまで）。カードの上には「引き継ぎ元」として、元のボードの日時・フォルダ・ID が薄く出ます

カードがすでにあるセッションでも、パネルの末尾の薄い 1 行（「前のセッションのボードを引き継ぐこともできます」）の [表示] から、同じ一覧を開けます。カードが 1 枚もない新しいセッションで、前のセッションに引き継げるボードがないときは、何も出ません。

### 確認が出るとき

このボードにすでにカードがあるときは、[引き継ぐ] を押すと、すぐには写さず、確認の段が出ます。何枚が入り、何枚が飛ばされ、何枚が入らないかが、カードのタイトルと id つきで並びます。[この内容で引き継ぐ] で写し、[やめる] で何もせず戻ります。

- 今のボードに同じ id のカードがあるときは、その 1 枚は飛ばして、今のカードをそのまま残します
- カードの上限（20 枚）を超える分は入りません。入らなかったカードは元のボードに残り、そのセッションを開けば読めます
- 今のボードが 20 枚でいっぱいのときは、1 枚も入らないと出ます。済んだカードを消してから引き継いでください
- 確認の段を出したあとにボードが変わったとき（Claude がカードを書いたなど）は、数え直した確認の段が出ます

### 元のボードは読み取り専用で残る

引き継ぐと、元のボードは消えずに残り、読み取り専用になります。元のボードのカードは書き換えません。引き継いだボードは、引き継ぎの一覧に出なくなります。

- 元のセッションを開くと、パネルの上に「読み取り専用」の枠が出て、いつ、どのセッションに引き継がれたかが読めます。カードはふだんどおり読めます
- 元のセッションの Claude は、ボードに書き込めません（`set_card`・`edit_card`・`append_card`・`remove_card`・`clear` が断られ、利用者に引き継ぎ先で書くよう伝えます）。`list_cards` では読めて、結果の先頭に読み取り専用だという 1 行が付きます。読み取り専用かどうかをストアから読めなかったときも、書き込みは断られます（もう一度試すか、利用者に知らせるよう伝えます）
- 例外: 0.9.1 より前の版のまま開いていたセッションは、読み取り専用を知らないので、書き込めてしまいます。そのセッションを開き直すと、読み取り専用になります
- 元のセッションでまた書きたいときは、枠の [このセッションで書けるように戻す] を押します。押しても、引き継ぎ先に写したカードは残ります。戻したボードは、また引き継ぎの一覧に出ます
- ボードの保存はセッションごとに分かれているので、引き継いだあとにどちらかのボードを変えても、もう一方には届きません

引き継ぐ前に、次の 2 点に気をつけてください。

- 一覧には、同じフォルダで並行して使っているセッションのボードも出ます。引き継ぎ元がまだ使われていないかを確かめてから [引き継ぐ] を押してください。押すと、そのセッションは書き込めなくなります（そのセッションで [このセッションで書けるように戻す] を押すと外せます）
- 2 つのセッションがほぼ同時に同じボードを引き継ぐと、両方に写しができることがあります（同時に押されたことを防ぐ仕組みはありません）。気づけたときは引き継ぎの結果の 1 行に出ますが、出ないこともあります

### 保存すること

引き継ぎの一覧で見分けられるように、ボードを保存するとき、次のことも一緒に保存します。

- 最初の依頼の先頭 60 文字（空白と改行は 1 つの空白にまとめます）。保存するのは、このバージョンを読み込んでから最初に入力した依頼で、ボードにまだ依頼が保存されていないときだけです。一度保存したら変わりません。再開したセッションで、まだ保存されていなかったときは、再開後の最初の入力になることがあります
- アプリが会話の題を渡してきたときは、その題
- 最後に書いた日時、フォルダの名前（上の階層は保存しません）、カードの枚数

最初の依頼と会話の題は、設定 `handover` がオフのときは覚えず、保存しません（オンのときに保存されたものは残ります）。

依頼の先頭に秘密を書いた場合は、その部分もストアに残ります。保存したくないときは、設定 `handover` をオフにします（引き継ぎの一覧も出なくなります）。前のバージョンで作ったボードには、最初の依頼やフォルダの名前が残っていないことがあります。そのときは「最初の依頼: 不明」、フォルダは「不明」と出ます（引き継ぎ自体はできます）。

## 本文に書けるもの

本文には Markdown が書けます（見出し、箇条書き、リンク、コード、表）。

### 図

本文の ` ```mermaid ` の囲みのうち、基本的な形のものは、パネルで図として描かれます。

- 描けるのは、`flowchart` / `graph`（向きは `TD` `TB` `BT` `LR` `RL`、ノードの形は四角・丸・円・ひし形、辺は `-->` `---` `-.->` `==>` と、辺の文字、`A --> B --> C` の連鎖、`A & B --> C`）と、参加者と矢印とメッセージだけの `sequenceDiagram` です
- 循環があっても描けます。図が大きすぎるとき（ノード 30 個、辺 60 本まで）は描きません
- 描けないもの（`subgraph`、ほかの種類の図、読み取れない書き方）や、図を出せない画面（ターミナル）では、コードブロックとして読める形で出ます。ASCII のテキストの図も同じです
- 図が広いときは、パネルの幅に合わせて縮みます。カードの本文そのもの（保存される内容、Claude が読み返す内容）は変わりません

## 上限

| 項目 | 上限 |
| --- | --- |
| カードの枚数 | 20 枚（固定したカードも数えます） |
| タイトル | 60 文字 |
| 本文 | 4000 文字 |
| id | 40 文字（英数字と `_` `-`） |

超えると Claude にエラーが返り、Claude が短くするか、済んだカードを消してからやり直します。

## Claude が使うツール

Claude は次の 6 つのツール（`mcp__whiteboard__` で始まります）でボードを操作します。ツールを初めて使うときに、許可を求められることがあります。

| ツール | 入力 | 内容 |
| --- | --- | --- |
| `set_card` | `id`, `title`, `body`, `pin`（省略できる） | カードを追加する。同じ `id` があれば上書きする。`pin` が `true` なら固定、`false` なら固定を外す。省略すると今のまま |
| `edit_card` | `id`, `find`, `replace`, `all`（省略できる） | カードの本文の一部だけを書き換える。本文の中の `find`（改行を含んでよい）を `replace` に置き換える。`find` がちょうど 1 箇所に一致するときだけ置き換え、見つからないとき、2 箇所以上に一致するときは断る。`all` が `true` なら、一致した箇所をすべて置き換える。`replace` を空にすると、その部分を消す。タイトル、固定、位置は変わらず、最後に書いた時刻は更新される |
| `append_card` | `id`, `text` | カードの本文の末尾に文を足す。本文が空でなければ、間に改行を 1 つ入れる。タイトル、固定、位置は変わらず、最後に書いた時刻は更新される |
| `remove_card` | `id` | カードを 1 枚消す |
| `clear` | なし | カードを全部消す |
| `list_cards` | なし、または `titles_only` / `id` / `query` | ボードを読む。引数なしは全カードを全文で返す。`titles_only: true` は目次（id、タイトル、本文の文字数）、`id` はそのカード 1 枚、`query` は空白で分けた語をすべて含むカードと一致した行（最大 5 行）を返す。パネルと同じ順で、固定のカードには `pinned: true` が付く |

Claude は、ボードの内容を尋ねられたら、まず `titles_only` か `query` で探し、必要なカードだけ `id` で読みます（引数なしは全文を返すので重いため）。「手順 3 を済みにして」のような頼みは、探したうえで `edit_card` で該当の行だけを書き換えます。カードの全文は書き直しません。

`edit_card` と `append_card` で本文が上限（4000 文字）を超えるときは、`set_card` と同じく断られます。カードがないときは、その旨が返ります。

このプラグインには、ボードの使い方を Claude に教えるスキル `whiteboard` が入っています。「ボードにこれを書いて」のような頼みで使われます。

## 設定

新しいセッションの Claude にも、ボードがあることが伝わるようにする案内を調整できます（`/config` のプラグインの設定、またはインストール時の設定）。

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| `handover` | オン | ボードが空のとき、パネルに前のセッションのボードの一覧と [引き継ぐ] を出し、帯にも「· 引き継げます」と足します。オフにすると、ほかのセッションのボードを読まず、最初の依頼と会話の題も保存しません。すでに読み取り専用になったボードが書き込めないままなのは、オフでも変わりません |
| `guide` | `short` | `off`: 何も足さない。`short`: システムプロンプトの末尾に短い 1 節を足す。ボードがあること、流れてしまう手順・URL・状況はカードに残すこと、読むときは `list_cards` を `titles_only` か `query` で呼ぶこと、使い方はツール検索（ToolSearch）で `whiteboard` を引くこと、を伝える。`full`: `short` に加えて、入力に下の語が含まれるときだけ、ツールの使い分け（`set_card`、`edit_card`、`append_card`、`list_cards`、固定）の要点を足す |
| `guideKeywords` | `ボード,whiteboard` | `full` のきっかけの語（カンマ区切り、大文字小文字は区別しない）。入力に 1 つでも含まれると、使い分けの要点を足す。足すのは 5 ターンに 1 回までで、入力欄の文字は変わらない |

`short` の節は、カードの内容や枚数を含まない毎回同じ文（約 120 文字）なので、会話のキャッシュを無駄にしません。

## 動作を確認した環境

- 帯とパネルの表示、カードの追加・上書き・削除、Markdown の表示、固定（先頭に並ぶこと）
- 図（`flowchart` と `sequenceDiagram` が描かれること、`subgraph` を含むものがコードブロックのままになること）。暗いテーマと明るいテーマの両方で見ています。窓を狭くしたときも、図と帯が使える範囲で収まることを見ています
- アプリを閉じて開き直したあとも、同じセッションのカードが残ること。スキル `whiteboard` が読み込まれて呼べること
- インストールした版（プラグインとして入れた版）で、パネルが開き、カードを追加できること

まだ確かめていないものです。

- 前のセッションのボードの引き継ぎ（一覧の表示、[中身を見る]、[引き継ぐ]、確認の段）、元のボードの読み取り専用（元のセッションの帯と枠、Claude への断り、[このセッションで書けるように戻す]）、設定 `handover`、保存する最初の依頼の表示。2 つのセッションを同時に開いたときの動きも含みます。0.9.1 で変えた、読み取り専用の印を別のキーに保存する形、パネルで [引き継ぐ] を押している間に Claude がカードを書いたときの動き、`/clear` のあとの別のセッション ID でのボードの表示も、デスクトップでは確かめていません
