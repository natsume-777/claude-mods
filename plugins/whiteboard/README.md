# whiteboard

Claude が書き込む作業ボード。手順、並行して動かしている処理、このセッションに関わるリンクなど、チャットで流れてしまう情報をカードにして残します。人は基本的に見るだけです。

## 何ができるか

ボードは、見出し（タイトル）と本文（Markdown）を持つカードの並びです。Claude が書き込み、右のパネルに追加した順に並びます。カードを上書きしても、位置は変わりません。Claude は、常に見ていたいカードを「固定」にでき、固定したカードはパネルの上に並びます（固定の中も、固定でない中も、追加した順です）。

- 入力欄の上の帯に「ボード 3件」と [開く] のボタンが出ます。サブエージェントが動いているときは、「ボード 3件 · 実行中 2」のように件数が付きます。カードが 1 枚もなく、動いているサブエージェントもないときは、帯は出ません
- [開く] を押すと、右のパネルにカードが順に並びます。カードごとに、タイトル、カードの id と最後に書いた時刻、本文が出ます。固定したカードには、タイトルの横に薄く「固定」と出ます
- カードがないときは、パネルに「まだ何も書かれていません」と出ます
- `/whiteboard` でもパネルを開けます
- カードは、このセッションに結び付けて保存されます。アプリを閉じて同じセッションを開き直すと、残っています。別のセッションからは見えません

本文には Markdown が書けます（コードブロックや表も使えます）。

### 図

本文の ` ```mermaid ` の囲みのうち、基本的な形のものは、パネルで図として描かれます。

- 描けるのは、`flowchart` / `graph`（向きは `TD` `TB` `BT` `LR` `RL`、ノードの形は四角・丸・円・ひし形、辺は `-->` `---` `-.->` `==>` と、辺の文字、`A --> B --> C` の連鎖、`A & B --> C`）と、参加者と矢印とメッセージだけの `sequenceDiagram` です
- 循環があっても描けます。図が大きすぎるとき（ノード 30 個、辺 60 本まで）は描きません
- 描けないもの（`subgraph`、ほかの種類の図、読み取れない書き方）や、図を出せない画面（ターミナル）では、これまでどおりコードブロックとして読める形で出ます。ASCII のテキストの図も同じです
- 図が広いときは、パネルの幅に合わせて縮みます。カードの本文そのもの（保存される内容、Claude が読み返す内容）は変わりません

関係や流れは、箇条書きや表でも伝わります。

この図の描画は、v2.1.289 のデスクトップアプリで確認しています（`flowchart` と `sequenceDiagram`、`subgraph` を含むものがコードブロックのままになること）。明るいテーマでの見え方は確かめていません。

## 並行処理

パネルの先頭には、カードとは別に「並行処理」の区画が出ます。サブエージェントが動き出すと自動で追加され、Claude に頼む必要はありません。

- 1 行に、種別（`Explore` など）、説明（Agent を呼ぶときに付けた短い説明）、状態（実行中／完了）が出ます
- 実行中のものが上に、完了したものは新しい順に最大 5 件が続きます。完了したものには、サブエージェントが最後に返した報告の 1 行目（見出しや強調などの Markdown 記号は除きます）が薄い字で付きます。報告が読み取れなかったものには付きません
- サブエージェントがまったくなく、下のバックグラウンドの作業もないときは、区画は出ません
- 読み取り専用です。カードには入らず、保存もされません。アプリを閉じると消えます

区画の下には、サブエージェント以外のバックグラウンドの作業が「バックグラウンド · ターン終了時点 23:01」のように、その時刻とともに並びます。

- バックグラウンドで動かしているコマンド（shell）、モニター、ワークフロー、これから実行される予約（cron）が対象です。1 行に、種別（`shell` など。予約は「予約」）、説明（説明が空のコマンドは、コマンドの先頭）、状態（実行中、待機中、予約は「くり返し」か「1 回」）が出ます。コマンドと予約の本文は、60 文字で切ります
- 内容は、ターンの終わりごと（とサブエージェントの終了ごと）の時点のものです。見出しの時刻は、その最後の時刻です。ターンの途中で終わったり増えたりしても、次のターンの終わりまで変わりません
- 最大 5 行です。超えた分は「ほか N 件」と数だけ出ます
- 入力欄の上の帯の「実行中 N」には、サブエージェントだけを数えます。バックグラウンドの作業だけでは、帯は出ません

この区画のうち、バックグラウンドのコマンド（shell）の行は、v2.1.289 のデスクトップアプリで確認しています。モニター、ワークフロー、予約の行はまだ確かめていません。

## ほかのセッションのボード

ボードはセッションごとに保存されます。新しいセッションで前のボードを使いたいときは、パネルの一番下の「ほかのセッションのボード」から取り込みます。Claude に頼むのではなく、人がパネルのボタンで操作します。

- 別のセッションに保存されたボードが 1 つでもあると、パネルの下に一覧が出ます。更新が新しい順に最大 5 件で、超えた分は「ほか N 件」と数だけ出ます。1 行に、更新の日時、フォルダ名（作業フォルダの最後の名前だけで、フルパスは出ません）、カードの枚数、カードのタイトルの先頭 3 つが出ます
- [取り込む] は、そのボードのカードを今のボードにコピーします。今のボードに同じ id のカードがあれば、今のものを残して飛ばします。20 枚の上限に達したら、入る分までです。固定の指定は引き継ぎます。取り込み元は消えません。結果は 1 行で、一覧の上に出ます（例「3 枚を取り込みました（1 枚は同じ id があるので飛ばしました）」）
- [消す] は、そのボードを保存先から消します。消す前に書き出すかどうかは、下の設定で決まります
- 一覧の見出しの横に、このプラグインがストアに保存している量が「ストア N KB」と出ます。その下の 1 行に、下の 2 つの設定が今どうなっているかが出ます
- 一覧は、パネルを開くたびに読み直します。開いている間に、ほかのセッションがボードを書いても、開き直すまで変わりません

古いボードが溜まらないよう、設定が 2 つあります。どちらも初期値はオフです。プラグインの設定から変えます。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `archiveDir` | 空（書き出さない） | 値があると、[消す] と自動掃除でボードを消す前に、Markdown のファイル `whiteboard-<日付>-<セッション ID の先頭 8 文字>.md` をこのフォルダに書きます。プロジェクトからの相対パスか、絶対パスで指定します。書き出せなかったボードは消しません。ファイルには、見出し、更新日時、フォルダ名と、カードごとのタイトル、id、時刻、固定、本文が入ります |
| `autoCleanDays` | 0（しない） | 1 以上だと、セッションの開始時に、ほかのセッションのボードのうち、最後の更新がこの日数より古いものを消します。`archiveDir` があれば、書き出してから消します。今のセッションのボードは、何日たっても消しません。更新の時刻が分からないボードも消しません。書き出しや削除に失敗したものは消さず、デバッグのログに 1 行出ます |

自動では何も消さないのが初期の状態です。容量が一杯になってカードを保存できないときも、自動では掃除しません。設定を入れるか、[消す] で消します。

`archiveDir` にプロジェクト内のフォルダを選ぶと、書き出したファイルがプロジェクトの変更に混ざります。コミットしたくなければ、`.gitignore` に足します。

```gitignore
# whiteboard の書き出し（archiveDir を .claude/whiteboard/ にした場合）
.claude/whiteboard/
```

この一覧、取り込み、[消す]、2 つの設定は、まだ実機で確かめていません。

## 使い方

Claude に頼みます。

```text
ボードに今日の作業手順を書いて
ボードに今開いているプレビューの URL を残して
ボードの手順 3 は？
ボードの手順 3 を済みにして
ボードのあれを消して
ボードを整理して
```

頼まなくても、Claude が手順や並行して動かしている処理の状況を、自分でボードに書くことがあります。書き換えと削除も Claude に頼みます。カードの書き換えにボタンはありません（ほかのセッションのボードの [取り込む] と [消す] だけがあります）。

Claude は次の 4 つのツール（`mcp__whiteboard__` で始まります）でボードを操作します。ツールを初めて使うときに、許可を求められることがあります。

| ツール | 入力 | 内容 |
| --- | --- | --- |
| `set_card` | `id`, `title`, `body`, `pin`（省略できる） | カードを追加する。同じ `id` があれば上書きする。`pin` が `true` なら固定、`false` なら固定を外す。省略すると今のまま |
| `remove_card` | `id` | カードを 1 枚消す |
| `clear` | なし | カードを全部消す |
| `list_cards` | なし、または `titles_only` / `id` / `query` | ボードを読む。引数なしは全カードを全文で返す。`titles_only: true` は目次（id、タイトル、本文の文字数）、`id` はそのカード 1 枚、`query` は空白で分けた語をすべて含むカードと一致した行（最大 5 行）を返す。パネルと同じ順で、固定のカードには `pinned: true` が付く |

Claude は、ボードの内容を尋ねられたら、まず `titles_only` か `query` で探し、必要なカードだけ `id` で読みます（引数なしは全文を返すので重いため）。

固定は、「今の手順の全体像」「URL の一覧」のような、人が常に見ていたいカードのためのものです。固定に枚数の上限はなく、20 枚の中に数えます。

このプラグインには、ボードの使い方を Claude に教えるスキル `whiteboard` が入っています。「ボードにこれを書いて」のような頼みで使われます。

## 上限

| 項目 | 上限 |
| --- | --- |
| カードの枚数 | 20 枚 |
| タイトル | 60 文字 |
| 本文 | 4000 文字 |
| id | 40 文字（英数字と `_` `-`） |

超えると Claude にエラーが返り、Claude が短くするか、済んだカードを消してからやり直します。

Claude Code v2.1.289 のデスクトップアプリ（Code タブ）で、帯とパネルの表示、カードの追加・上書き・削除を確認しています。「並行処理」の区画（実行中・完了の切り替え、完了行の 1 行目の表示、帯の「実行中 N」）も確認しています。
